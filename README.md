# The Finance Lawyer

Static article site. No build step.

- `index.html` lists the articles, newest first.
- `articles/` holds one HTML file per article.
- `about.html` is the about page.
- `css/style.css` holds all styling.

To add an article, copy a file in `articles/`, change the title, date and body, then add one line to the list in `index.html`.
