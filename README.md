# The Finance Lawyer

Static essay site. No build step.

- `index.html` lists the essays, newest first.
- `essays/` holds one HTML file per essay.
- `about.html` is the about page.
- `css/style.css` holds all styling.

To add an essay, copy a file in `essays/`, change the title, date and body, then add one line to the list in `index.html`.
